# Voice AI LinkedIn Carousel Website

## Goal
Create a polished six-slide web presentation that feels like a premium LinkedIn carousel and keeps viewers swiping through the full story.

## Experience
- Build the supplied copy into six focused 1920×1080 slides with large, readable typography.
- Use Geist for display text, Geist Mono for technical labels, and Inter for body copy.
- Apply an Apple-inspired editorial style: crisp white surfaces, near-black type, electric green accents, thin rules, and restrained motion.
- Turn architecture, benchmark, market-loss, and latency captions into clear visual diagrams rather than plain text.
- Add previous/next controls, keyboard navigation, progress, slide thumbnails, fullscreen presentation, and a print-ready view for PDF export.
- Keep the active slide in the URL so refreshes and shared links open to the same slide.

## Technical details
- Implement a fixed 1920×1080 slide canvas that scales cleanly on desktop and mobile.
- Use reusable slide layout and diagram components, semantic design tokens, and accessible controls.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Verify the finished presentation visually at desktop and mobile sizes, plus keyboard and fullscreen behavior.
